# ADR-0003：不可见 VM 与不存在 VM 不可区分

- 状态：已接受
- 日期：2026-10-25
- 相关安全不变量：**不变量 2**（存在性不泄露）

## 背景

多会话共用一台宿主时，会话 A 不应能探测出"宿主上还存在别的 VM"——否则
模型可以通过枚举 VM id 推断其他租户/任务的拓扑（侧信道）。常见错误实现是
对"不存在"返回 404、对"无权限"返回 403，两者报文不同，模型据此区分。

## 决策

1. `vm_list` 只返回**当前会话快照中 `granted_vm_ids` 内**且仍已注册的 VM；
2. 任何按 id 访问的 tool（`vm_status` / `vm_start` / …）对**不在可见集合**的
   id 与**根本未注册**的 id 返回**完全相同的脱敏错误**：
   `"VM 不存在或无权限"`（`VMNotVisibleError.public` 与 `PermissionDeniedError.public`
   在该场景下取值一致）；
3. 审计内部仍记录真实原因（`deny_reason = "vm 'x' not in session grants"`），
   仅对模型侧脱敏——存在性信息只进审计，不进模型可见输出；
4. 连续探测触发限流与 `security.probe_alert` 告警（PermissionEngine 探测窗口）。

## 后果

- 模型无法通过错误报文差异推断 VM 是否存在；
- 运维仍能在审计日志中看到探测行为并收到告警；
- 代价：模型侧调试信息更少（只能靠 `vm_list` 确认可见集合），属可接受权衡。
